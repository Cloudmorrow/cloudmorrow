Use it everywhere

  1. On a computer

    One line in a terminal installs the terminal app, cm, and on a computer with a desktop, the Cloudmorrow desktop app that also mounts your fileshares:

    $ curl -fsSL __BASE_URL__/install.sh | sh
    Needs Python 3.11 or newer. It installs into __VENV_HINT__ and signs this computer in to __BASE_URL__. Linux today; macOS and Windows next.
  2. On a phone

    Open __BASE_URL__/app, sign in, and add it to the home screen. It works like an app, with notifications.

  3. With an assistant

    Claude, or any assistant that speaks MCP, can work with your cloud as you, once you say yes: its address is __BASE_URL__/mcp.

Add more

Everything your cloud does is a quill. Administrators add them from Administration → Quills, or with cm quill add <name>. See what there is in the Quill Catalog.
